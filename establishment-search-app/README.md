# Estabelecimento Search App

Este projeto é uma aplicação web que permite aos usuários buscar estabelecimentos próximos a sua localização. A aplicação utiliza a API do Google Maps para exibir um mapa interativo e listar os resultados de busca.

## Estrutura do Projeto

- `index.html`: Documento HTML principal que contém a estrutura da página, incluindo cabeçalho, controles de busca, filtros para diferentes tipos de estabelecimentos, seção de mapa e seção de resultados.
- `style.css`: Arquivo de estilos que define o layout, cores, fontes e outros aspectos visuais dos elementos HTML para garantir uma interface amigável ao usuário.
- `app.js`: Código JavaScript que gerencia as interações do usuário, como busca de estabelecimentos com base no endereço ou localização atual, filtragem de resultados e integração com a API do Google Maps.

## Como Usar

1. **Clone o repositório**:
   ```
   git clone <URL do repositório>
   ```

2. **Abra o arquivo `index.html` em um navegador**.

3. **Digite um endereço ou clique no botão de localização para encontrar estabelecimentos próximos**.

4. **Use os filtros para refinar sua busca por tipo de estabelecimento**.

## Dependências

- Google Maps JavaScript API
